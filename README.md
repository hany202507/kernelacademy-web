# Kernel Academy — 재무 AI 표준 커리큘럼

재무·회계 실무자를 위한 AI 활용 표준 커리큘럼과 그 웹사이트입니다.
커리큘럼·강의자료·실습 데이터를 전면 공개합니다.

- 사이트: https://kernelacademy.io
- 발행: 주식회사 커널스페이스

## 이 저장소의 구조

| 경로 | 무엇 |
|---|---|
| `canon/` | **정본.** 6개 기능(R·C·P·J·V·D)과 7개 업무 워크플로. 사이트는 이 문서를 렌더링합니다 |
| `site/` | Astro 정적 사이트 소스 |
| `skills/` | 강의자료를 같은 스타일로 만드는 Claude Code 스킬. 설치법은 `skills/README.md` |

`canon/` 이 단일 출처입니다. 내용을 고칠 때는 `canon/` 을 먼저 고칩니다 —
사이트에만 고치면 다음 렌더링에서 유실됩니다.

## 로컬에서 돌리기

```bash
cd site
npm install
npm run dev
```

`npm run build` 는 빌드 후 금칙어 검사를 함께 돌립니다.
민간자격 등록증 발급 전까지 「자격·인증·검정·공인」을 쓸 수 없으므로,
산출물에 하나라도 남으면 빌드가 실패합니다.
