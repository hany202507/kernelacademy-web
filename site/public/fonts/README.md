# 웹폰트

이 폴더는 `scripts/vendor-fonts.sh` 가 만듭니다. 손으로 고치지 마십시오.

직접 호스팅하는 이유는 성능이 아니라 **개인정보**입니다.
Google Fonts·jsDelivr 에서 불러오면 가입하지 않고 읽기만 하는 방문자도
매 페이지마다 IP 가 국외로 전달됩니다.
